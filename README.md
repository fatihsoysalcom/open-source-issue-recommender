# Open Source Issue Recommender

This script demonstrates the core concept of IssuePilot AI: intelligently matching open-source contributors to suitable tasks. It simulates an AI-powered recommendation system that suggests open-source issues based on a user's skills and experience level. The example highlights how a simple matching algorithm can guide developers to relevant contribution opportunities.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
